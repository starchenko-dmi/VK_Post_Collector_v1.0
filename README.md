# VK Post Collector 📊

**Десктопное приложение для автоматического сбора постов из сообществ ВКонтакте с сохранением полного текста в Excel.**  
Позволяет маркетологам, аналитикам и исследователям быстро выгружать контент из до 30 групп за заданный период, обходя ограничения на длину текста в Excel и соблюдая рейт-лимиты API ВКонтакте.

---

## ✨ Функционал

*   **Графический интерфейс (GUI):** Интуитивно понятное окно на базе Tkinter с вкладками «Настройки» и «Запуск», прогресс-баром и цветной консолью логов.
*   **Массовый сбор:** Поддержка до 30 сообществ за один запуск (по цифровому ID или короткому имени).
*   **Гибкая фильтрация:** Выбор произвольного периода сбора (дата «С» и «По»).
*   **Полное сохранение текста:** Автоматическая обработка постов длиннее 32 767 символов (лимит Excel) с выгрузкой полного текста в отдельные `.txt` файлы и ссылкой на них в таблице.
*   **Очистка данных:** Автоматическое раскрытие упоминаний вида `[id123|Имя Фамилия]` и склейка текста оригинала при обработке репостов (`copy_history`).
*   **Двухуровневая система токенов:** Встроенный токен по умолчанию (для мгновенного старта) + возможность для пользователя ввести и сохранить свой личный токен.
*   **Кроссплатформенная совместимость токенов:** Механизм обфускации, позволяющий сохраненному пользовательскому токену работать при переносе приложения на другой ПК.

---

## 🏗 Архитектурные решения и особенности

1. **Многопоточность и отзывчивость UI:**  
   Сбор данных выполняется в отдельном потоке (`threading`), а коммуникация с интерфейсом происходит через потокобезопасную очередь (`queue.Queue`). Это предотвращает «зависание» окна во время сетевых запросов.
2. **Работа с API ВКонтакте:**  
   Используется библиотека `vk-api`. Реализован кастомный механизм соблюдения рейт-лимитов (`time.sleep(0.25)`), а также автоматическая обработка ошибок `ApiError` (код 6 – Too many requests, код 15 – Access denied).
3. **Обход ограничений Excel:**  
   При экспорте через `openpyxl` текст постов проверяется на длину. Если длина > 32 767 символов, текст сохраняется в папку `полные_тексты/`, а в ячейку Excel записывается путь к файлу.
4. **Безопасное хранение конфигурации:**  
   Пользовательские настройки и токены хранятся не в папке проекта, а в защищенной директории ОС: `%APPDATA%\VK_Collector_Config\config.json`. Токен обфусцируется с использованием Base64 и статической соли, что обеспечивает работу на любом компьютере без привязки к `COMPUTERNAME`.
5. **Модульная архитектура:**  
   Четкое разделение ответственности: `gui` (интерфейс), `core` (бизнес-логика и API), `utils` (конфигурация, логирование, безопасность).

## 🛠 Стек технологий

*   **Язык:** Python 3.8 – 3.13
*   **Менеджер зависимостей:** Poetry
*   **GUI:** `tkinter`, `tkcalendar`
*   **Работа с API:** `vk-api`, `requests`
*   **Экспорт данных:** `openpyxl`
*   **Сборка в исполняемый файл:** `PyInstaller`
*   **Логирование:** встроенный модуль `logging` с кастомным QueueHandler

## 🚀 Инструкции по запуску (для разработчиков)

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/vk-post-collector.git
cd vk-post-collector
```

### 2. Настройка окружения
Убедитесь, что у вас установлен [Poetry](https://python-poetry.org/docs/#installation).
```bash
# Установка всех зависимостей проекта
poetry install
```

### 3. Конфигурация (опционально)
Создайте файл `.env` на основе шаблона, если хотите переопределить токен по умолчанию через переменные окружения (приоритет выше, чем у `default_token.py`):
```bash
cp .env.example .env
# Откройте .env и вставьте ваш BASE64 токен в DEFAULT_TOKEN_B64
```

### 4. Запуск приложения
```bash
# Запуск через виртуальное окружение Poetry
poetry run python src/main.py
```

## 💻 Примеры использования

### Интерфейс приложения
1. **Вкладка «Настройки»:**  
   Вставьте токен (ПКМ → Вставить), нажмите «Проверить токен».  
   Введите группы (например, `molodeg_ubn`, `public52240322`), выберите даты и папку для сохранения.
2. **Вкладка «Запуск»:**  
   Нажмите `▶️ Старт сбора`. Наблюдайте за прогрессом в цветной консоли логов.  
   По завершении нажмите `📁 Открыть папку с результатами`.

### Результат работы
В выбранной директории будут созданы:
*   `отчёт_20260202_162027.xlsx` — таблица со столбцами: `Группа_ID`, `Группа_название`, `Пост_ID`, `Дата_публикации`, `Текст_полный`, `Лайки`, `Репосты`, `Комментарии`, `Ссылка_на_пост`.
*   Папка `полные_тексты/` — содержит `.txt` файлы для постов, превышающих лимит символов Excel.

## 📦 Сборка в .exe (для распространения)

Для создания автономного исполняемого файла Windows без необходимости установки Python:

```bash
# Активация оболочки Poetry
poetry shell

# Установка PyInstaller
pip install pyinstaller==6.18.0

# Сборка (одним файлом, без консоли, с иконкой)
pyinstaller --onefile --windowed --name "VK Post Collector" \
  --icon "resources/app.ico" \
  --hidden-import "tkinter" \
  --hidden-import "tkcalendar" \
  --hidden-import "vk_api" \
  --hidden-import "openpyxl" \
  --hidden-import "tzdata" \
  --add-data "src;src" \
  src/main.py
```
Готовый файл будет находиться в папке `dist/VK Post Collector.exe`.

## 🛡 Безопасность и лучшие практики репозитория

*   **`.gitignore`:** Настроен на исключение конфиденциальных данных (`config.json`, `.env`), байт-кода (`__pycache__`, `*.pyc`), временных файлов сборки (`build/`, `dist/`, `*.spec`) и логов (`logs/`).
*   **`.env.example`:** Предоставляет шаблон необходимых переменных окружения без реальных секретных ключей.
*   **История коммитов:** В проекте используется семантическое именование коммитов (Conventional Commits) для чистоты истории:
    *   `feat(gui): add context menu for token pasting`
    *   `fix(core): resolve tzinfo datetime error in excel exporter`
    *   `docs(readme): update architecture section and launch instructions`
    *   `chore(deps): update poetry dependencies`
